开发预览版，versionCode 5。本地构建正式签名 APK 供手机覆盖测试。
本轮只提交和同步 Git 源码，不创建、更新或上传 GitHub Release，也不创建发布标签。
最新正式版仍为 1.2.1，正式发布等待用户实际测试或后续确认。

改动与行为
从目录重新打开视频，默认仍为原全屏交互模式；手机按钮进入独立竖屏模式，展开按钮返回全屏。
同一个 Activity、播放器和队列完成模式切换，不重新打开视频；位置、暂停、倍速及随机历史保留。
竖屏固定为竖向等比适配，不裁剪拉伸；左右滑动保持原连续毫秒进度曲线及预览。
上下滑动仅在竖屏切集，上滑下一条、下滑上一条；短滑回弹，斜向轴锁，多指/取消不切集。
顺序模式按队列顺序切换，随机模式使用现有随机牌组及观看历史，单集循环自然循环而允许手动切集。
全屏原亮度/音量手势、长按临时倍速、单集循环、加载延迟、缩略图内存上限及冷启动扫描规则保留。
竖屏不添加社交按钮或长期遮挡画面的操作说明。模式按钮和菜单均可调整播放顺序。

构建及静态检查
assembleDebug、assembleDebugAndroidTest、testDebugUnitTest、lintDebug、assembleRelease 成功。
17 项单元测试全部通过，覆盖连续进度、亮度/音量、随机历史和竖屏距离/速度/回弹判定。
