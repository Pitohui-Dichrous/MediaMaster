映序 1.3.0 正式版采用三窗口预载竖屏播放，基于用户已实机认可的版本发布。

- 点击手机图标进入竖屏，上滑下一条、下滑上一条；相邻视频提前准备，画面连续跟手。
- 点击全屏按钮随时切回原播放模式，保留进度、暂停状态和倍速；横滑继续精细调进度。
- 顺序、随机、单集循环均支持手动切集；随机模式可沿实际观看历史返回。
- 保留透明控件、画面预览、长按两倍速及文件管理；缩略图仅使用有容量上限的内存缓存。

**安装：** 下载 `MediaMaster-1.3.0.apk` 后在手机上打开。已有正式版或预览版时直接覆盖安装，**不要先卸载**；同一签名保留原有设置和添加的文件夹记录。

支持 Android 8.0 及以上，主要面向 Android 14。首次使用按提示授权读取视频。

附件中的 `INSTALL.txt` 为使用说明，`VERIFICATION.txt` 为本版验证记录，`SHA256SUMS.txt` 为校验清单；`MediaMaster-1.3.0-source.zip` 为开发源码，手机安装只需 APK。
