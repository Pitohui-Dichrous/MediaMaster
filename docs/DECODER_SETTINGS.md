# 解码选择

适用版本：`2.2.0-test.5` 测试分支。入口：主页设置 → 解码。选择保存到本机，之后打开的视频使用新设置。

| 选项 | 行为 |
| --- | --- |
| 优先软解 | 高分辨率、高帧率也先尝试软解，忽略先前的避用记录；不因播放较慢自动切换，仅在真实错误或持续无解码进展时恢复到备用路径。 |
| 默认解码 | 对规格明确的常见 SDR、8-bit 视频，最高 1080p/60fps，结合当前内存余量、温度状态和逐文件播放表现选择。信息不明、超出范围或资源紧张时优先硬解；没有型号或品牌白名单。 |
| 优先硬解 | 先尝试硬解；真实失败时依次尝试兼容引擎和软解。 |

未设置时采用“默认解码”。三项的保存值沿用 `native_decoder_mode`：默认为 `0`、硬解优先为 `1`、软解优先为 `2`；界面按软解、默认、硬解排列。

软件解码不保证更流畅。不同编码、参考帧结构、设备负载和温度都会影响结果；优先选项表达尝试顺序，不承诺固定延迟或禁止必要的错误恢复。默认模式也不同时运行多个解码器逐文件测速。

本版保留上述偏好含义，增加有界索引识别与资源允许时的软件线程调整，并修正定位输出观察的代际和进展判断。实现与验证范围见 [长 GOP 定位策略](LONG_GOP_SEEK.md)。此前 `test.4` 的记录见 [解码设置验证](DECODER_SETTINGS_VERIFICATION.md)。

[早期定位对照](SEEK_PERFORMANCE_TEST.md)和[持续定位记录](SEEK_STRESS_TEST.md)属于历史测试包，不替代本版验证，也不能外推为所有设备的性能保证。
