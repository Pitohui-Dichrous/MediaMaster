# 通用解码选择验证

版本：`2.2.0-test.4`，versionCode `21`。日期：2026-11-01。测试分支：`codex/test-seek-performance`；未合并主分支或发布正式 Release。

## 行为与回归

- 删除生产选择策略中的型号、品牌白名单；测试输出不再记录设备型号。媒体参数、实时内存/温度与逐文件播放反馈参与默认选择。
- 设置中的“优先软解 / 默认解码 / 优先硬解”按此顺序显示、保存并应用。新增实机测试确认真实 1080p60 合成视频在资源允许时走默认软解，显式软解忽略旧性能避用记录，硬解优先保持暂停定位正确。
- 优先软解不因规格、掉帧或速度偏慢而退出；原生错误或持续没有解码进展才恢复。定位阶段连续无进展窗口为 10 秒，首帧准备为 12 秒；期间仍有解码或新画面进展会延后判定。
- 保留最新定位意图优先、跨手势有界队列、画面确认、异步释放、竖屏预载和音频隔离。
- 构建通过；114 项单元测试全部通过，lint 0 错误、36 项警告。4 项新增实机测试、40 项播放/预载/定位回归和 4 轮持续定位检查全部通过，没有跳过用例。
- UI 审查沿用现有主题与原生单选对话框，只有必要的选项文字，没有新增说明副标题；实际点击、选中状态、取消及持久化已验证。

## 持续定位

本轮仅使用生成的测试视频，未读取私人视频。设备条件仅记录 Android 14 / API 34；这不是跨设备性能认证。

同一冻结 APK、同一公开 H.264 High 720p60 样片（8 秒、250 帧 GOP、可从画面读出的帧编号），每轮按 12 Hz 输入 30 秒，共 360 次实际触摸。默认模式本轮选择软解。

| 模式 | 状态 | 点击区间最长观测画面不变 | 最终目标画面恢复 |
| --- | --- | ---: | ---: |
| 默认解码 | 播放 | 98 ms | 92 ms |
| 默认解码 | 暂停 | 186 ms | 118 ms |
| 优先软解 | 播放 | 117 ms | 75 ms |
| 优先硬解 | 播放 | 635 ms | 454 ms |

四轮均完整送达 360 组按下/抬起，输入节奏有效；测量期间没有重建播放器或替换解码器，采样失败及主线程快照超时均为 0，退出后原生播放器占用与隔离队列均归零。最终落点以视频内嵌帧编号核对，暂停状态保持暂停，播放状态继续推进。

表中为该次采样的结果，既不是每次定位延迟的分位数，也不证明所有视频零等待。采样会受到画面变化及采样间隔影响，原始运行摘要同时保留输入节奏和独立落点核对。软解不保证在每台设备或每种媒体上更快；HDR、高位深、超出默认软解规格的视频，以及其他厂商硬件均未完成全面实机覆盖。
