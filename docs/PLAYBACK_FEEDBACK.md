# 播放入口与观看反馈

开发版 `2.5.1-dev.3` 沿用安装体积优化配置，不改变解码器、定位策略或图案资源。

| 入口与行为 | 观看记录 | 额外评价 |
| --- | --- | --- |
| 普通目录、未搜索时的随机入口、外部打开 | 实际观看超过 3 秒计一次 | 实际观看大于 0.5 秒、小于 1.5 秒后手动切走或关闭，额外点踩一次 |
| 从搜索结果进入的整个播放器队列（含筛选结果内随机播放） | 所有视频均不增加观看次数 | 无快速点踩；实际观看超过 3 秒，额外点赞一次 |

恰好 0.5 秒或 1.5 秒不触发点踩；恰好 3 秒尚不计观看或点赞。只累计前台实际播放时间，暂停、加载、定位等待、后台和预载邻页不计入。自然结束、播放失败及窗口重建不是快速划走；同一视频的自然循环继续累积当前条目的观看时间。

额外评价在后台单独记录，不点亮按钮、不展示特效、不振动，也不占用手动赞踩名额。一次播放器窗口内，一个视频最多获得一次额外点踩；同一轮搜索中，一个视频最多获得一次额外点赞，包括返回列表后重新打开播放器。手动同向赞踩可以另外计入；手动反向赞踩会撤回该范围内的额外评价，并阻止其再次产生。例如划走后返回并手动点赞，会撤回这次额外点踩，再记入手动点赞。随后取消手动点赞只撤回手动部分，不恢复已取消的额外点踩。

搜索关键词变化或清空后重搜开始新一轮；仅刷新、排序、大小写或首尾空格变化、返回列表、切换显示模式或窗口重建均沿用原轮次。搜索去重记录仅留在有界内存中，不保存永久选中状态。进程结束或内存中旧轮次被淘汰后，恢复的旧搜索窗口仍免计观看，但停止额外点赞以防重复；改变搜索关键词可开始新轮次。普通手动赞踩仍可使用。

所有观看分数、赞踩量及撤销贡献使用同一 **3 天半衰期**。既有数据和时间戳保留，按新半衰期更快衰减；概率下限、数值保护及 5 MB 数据库容量限制保留。重置权重使旧的异步额外评价失效。成功删除视频后，移除对应数据库记录、待写记录和活动贡献，防止旧回调写回；取消或失败的删除不清理权重。

全屏模式的赞踩按钮位于左下播放顺序按钮右侧；竖屏模式保留右上位置。计数不使用固定最大宽度或省略号。常规屏幕保持单行；窄屏或放大字体下适度分行，保留完整数量和 48dp 触控区域。竖屏控件隐藏时，首次单击仅显示控件；显示状态下单击播放或暂停。双击点赞及其图案效果不变。

验证使用独立数据库、专用模拟器和生成的视频，不以用户媒体作为测试数据。覆盖时间边界、搜索全队列与重复打开、手动/额外评价分离及撤回、衰减/重命名/重置/删除/容量淘汰，以及播放器生命周期、触摸和不同宽度/字体布局。
