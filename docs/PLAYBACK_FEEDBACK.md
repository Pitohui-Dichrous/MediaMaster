# 播放入口与观看反馈

开发版 `2.5.1-dev.2` 沿用安装体积优化配置，不改变解码器、定位策略或图案资源。

| 入口与行为 | 观看记录 | 自动反馈 |
| --- | --- | --- |
| 普通目录、随机入口、外部打开 | 实际观看超过 3 秒计一次 | 不足 1.5 秒手动切走或返回时，记一次点踩 |
| 点击搜索结果，直接打开的当前视频 | 不增加观看次数 | 不快速点踩；实际观看超过 3 秒记一次点赞 |
| 从搜索进入后切到其它条目 | 恢复普通规则 | 恢复普通规则 |

恰好 1.5 秒不触发点踩；恰好 3 秒尚不计观看或点赞。只累计前台实际播放时间，暂停、加载、定位等待、后台和预载邻页不计入。自然结束、播放失败及窗口重建不是快速划走；同一条视频的自然循环继续累积当前条目的观看时间。

自动反馈复用现有赞踩权重、七天半衰期及数据库容量限制，不新增永久的“已点赞”状态。同一播放窗口的同一视频只接受一次自动反馈；手动赞踩及手动取消优先，可以覆盖或撤销自动反馈。自动操作不弹出图案、不振动，控件状态会同步更新。重置权重会使旧的异步自动反馈失效。

全屏模式的赞踩按钮位于左下播放顺序按钮右侧；竖屏模式保留右上位置。计数不再使用固定最大宽度或省略号。常规屏幕保持单行；窄屏或放大字体下适度分行，保留完整数量和 48dp 触控区域，播放器控件仍按原规则隐藏。

验证覆盖：纯计时阈值与恢复、数据库可撤销反馈/衰减/重命名/重置/容量淘汰、实际播放器生命周期及不同宽度/字体下的布局。测试使用独立数据库与生成的视频，不读取用户私人视频。
